
# 🧠 AI Knowledge Retention Predictor

An interactive Streamlit application that predicts cognitive memory retention using mathematical forgetting curves and generates AI quizzes powered by Google Gemini.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://ai-knowledge-retention-prediction.streamlit.app)

## Overview
- **Retention Predictor:** Calculates memory retention decay using Ebbinghaus forgetting curve models.
- **AI Quiz Generator:** Generates topic-specific quizzes using Gemini AI.
- **Session Tracking:** Stores study history and quiz performance locally via SQLite.
